# fallpair-sdk

**FallPair · the bond-partner discovery · sovereign · runs in your browser** — sovereign SDK extracted from `fallpair/index.html`.

## Install
```bash
npm install @ai-native-solutions/fallpair-sdk
```

## Use
```js
import * as fallpair from '@ai-native-solutions/fallpair-sdk';
```
